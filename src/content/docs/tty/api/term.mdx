The term module creates a WASM-backed renderer that converts UI ops into ANSI escape sequences.

## createTerm(options)

Creates a renderer instance. Both dimensions are required.

```ts twoslash
import { createTerm } from "@bomb.sh/tty";

async function main() {
  let term = await createTerm({ width: 80, height: 24 });
}
```

| Option | Type | Description |
|---|---|---|
| `width` | `number` | Terminal width in columns |
| `height` | `number` | Terminal height in rows |

Returns a `Term` with a `render()` method and an `update()` method.

## term.render(ops, options?)

Renders a frame and returns the result.

```ts twoslash
import { close, createTerm, open, text, grow } from "@bomb.sh/tty";

async function main() {
  let term = await createTerm({ width: 80, height: 24 });

  let { output, events, info, errors, animating } = term.render([
    open("root", { layout: { width: grow(), height: grow() } }),
    text("Hello"),
    close(),
  ]);

  process.stdout.write(output);
}
```

### RenderOptions

| Option | Type | Description |
|---|---|---|
| `pointer` | `{ x, y, down }` | Pointer position and button state for hit testing |
| `deltaTime` | `number` | Seconds since last frame (for transitions). Auto-computed if omitted |
| `mode` | `"line"` | Render into a line region instead of full screen |
| `row` | `number` | Starting row for line mode (1-based, DSR format) |

### Pointer detection

Pass pointer state to get hit-testing events alongside output:

```ts twoslash
import {
  close,
  createTerm,
  fixed,
  grow,
  open,
  text,
} from "@bomb.sh/tty";

async function main() {
  let term = await createTerm({ width: 80, height: 24 });

  let { output, events } = term.render(
    [
      open("root", {
        layout: { width: grow(), height: grow(), direction: "ltr" },
      }),
      open("sidebar", {
        layout: { width: fixed(20), height: grow() },
      }),
      text("Sidebar"),
      close(),
      open("main", { layout: { width: grow(), height: grow() } }),
      text("Main content"),
      close(),
      close(),
    ],
    { pointer: { x: 5, y: 2, down: false } },
  );

  for (let event of events) {
    // { type: "pointerenter", id: "sidebar" }
    // { type: "pointerleave", id: "sidebar" }
    // { type: "pointerclick", id: "main" }
  }
}
```

### RenderResult

| Property | Type | Description |
|---|---|---|
| `output` | `Uint8Array` | ANSI bytes to write to stdout |
| `events` | `PointerEvent[]` | Pointer enter/leave/click events |
| `info` | `RenderInfo` | Element bounds lookup |
| `errors` | `ClayError[]` | Layout errors from Clay |
| `animating` | `boolean` | `true` when transitions are still running |

### RenderInfo.get(id)

Returns element bounds for a given id, or `undefined` if not found:

```ts twoslash
import { close, createTerm, open, text, grow } from "@bomb.sh/tty";

async function main() {
  let term = await createTerm({ width: 80, height: 24 });
  let { info } = term.render([
    open("root", { layout: { width: grow(), height: grow() } }),
    text("Hello"),
    close(),
  ]);
  let bounds = info.get("root")?.bounds;
}
```

### PointerEvent

| Type | Shape |
|---|---|
| `pointerenter` | `{ type: "pointerenter", id: string }` |
| `pointerleave` | `{ type: "pointerleave", id: string }` |
| `pointerclick` | `{ type: "pointerclick", id: string }` |

### ClayError

Layout errors include a `type` and `message`. Known error types:

- `TEXT_MEASUREMENT_FUNCTION_NOT_PROVIDED`
- `ARENA_CAPACITY_EXCEEDED`
- `ELEMENTS_CAPACITY_EXCEEDED`
- `TEXT_MEASUREMENT_CAPACITY_EXCEEDED`
- `DUPLICATE_ID`
- `FLOATING_CONTAINER_PARENT_NOT_FOUND`
- `PERCENTAGE_OVER_1`
- `INTERNAL_ERROR`
- `UNBALANCED_OPEN_CLOSE`
- `CLIP_DEPTH_EXCEEDED`

## term.update(options)

Resizes the renderer in place. Call it when the terminal changes size instead of creating a new `Term`, which would load the WebAssembly module again:

```ts twoslash
import process from "node:process";
import { close, createTerm, grow, open, text } from "@bomb.sh/tty";

async function main() {
  let term = await createTerm({
    width: process.stdout.columns,
    height: process.stdout.rows,
  });

  function frame() {
    let { output } = term.render([
      open("root", { layout: { width: grow(), height: grow() } }),
      text("Hello"),
      close(),
    ]);
    process.stdout.write(output);
  }

  process.stdout.on("resize", () => {
    term.update({
      width: process.stdout.columns,
      height: process.stdout.rows,
    });
    process.stdout.write("\x1b[2J");
    frame();
  });

  frame();
}
```

`update()` takes one of two forms:

| Option | Type | Description |
|---|---|---|
| `{ width, height }` | `number`, `number` | The new size in columns and rows |
| `{ events }` | `Array<{ type: string }>` | A list of events. Only `{ type: "resize", width, height }` events are read, and the last one wins |

`update()` is synchronous. After a real size change, the next `render()` redraws every cell. An update to the same size changes nothing.

`update()` does not clear the screen. When the terminal shrinks, cells outside the new size stay visible, so clear the screen before the next frame, as the example does with `\x1b[2J`.

`update()` also empties the `output` of earlier renders. Write each frame's output before you call `update()`, or copy it with `output.slice()`.

<Aside type="note">
In 0.9.0, the [input parser](/docs/tty/api/input) does not produce `resize` events. Build them from your runtime's resize signal, such as `process.stdout`'s `"resize"` event in Node or `SIGWINCH` in Deno.
</Aside>

## Frame loop with transitions

When using transitions, gate your render loop on `animating`:

```ts twoslash
import { close, createTerm, open, text, grow } from "@bomb.sh/tty";

async function main() {
  let term = await createTerm({ width: 80, height: 24 });

  function frame() {
    let { output, animating } = term.render([
      open("root", { layout: { width: grow(), height: grow() } }),
      text("Animating..."),
      close(),
    ]);
    process.stdout.write(output);
    if (animating) setTimeout(frame, 16);
  }

  frame();
}
```

<Aside type="note">
Line mode (`mode: "line"`) renders into a region of the main screen scrollback instead of the alternate buffer. See the [inline regions example](https://github.com/bombshell-dev/tty/blob/main/examples/inline-regions/index.ts).
</Aside>

## Types

The module exports a type for each shape on this page:

| Type | Describes |
|---|---|
| `Term` | What `createTerm()` returns |
| `TermOptions` | The options of `createTerm()`, `width` and `height` |
| `UpdateOptions` | The options of `update()`, in either form |
| `TermResizeEvent` | A `{ type: "resize", width, height }` event that `update()` reads |
| `RenderOptions`, `RenderResult` | The options and the result of `render()` |
| `RenderInfo` | The `info` lookup in a render result |
| `ElementInfo` | What `info.get(id)` returns, `{ bounds }` |
| `BoundingBox` | An element's `bounds`, with `x`, `y`, `width`, and `height` |
| `PointerEvent`, `ClayError` | The entries of `events` and `errors` |
